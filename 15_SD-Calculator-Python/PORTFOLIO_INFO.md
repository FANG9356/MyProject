# Project Portfolio Information

## ชื่อโครงการ
โปรแกรมคำนวณค่า S.D. ด้วย Python (Standard Deviation & Questionnaire Analysis Desktop Application)

## ผู้พัฒนา
ภคพล สุขมี (Phakhaphon Sukmee)

## หมวดหมู่
Desktop Application / Data Science & Statistics / Python Software

## เทคโนโลยีที่ใช้
- ภาษาหลัก: Python 3
- ส่วนติดต่อผู้ใช้ (GUI): Tkinter, ttk (Treeview, Scrollbar, Canvas Widgets)
- การประมวลผลเชิงตัวเลข: NumPy (Vectorized Arrays, Axis-wise Operations)
- การคอมไพล์เป็นไบนารี: PyInstaller (Standalone Windows Executable S.D.exe)

## สรุปภาพรวมและผลการดำเนินงาน
โปรแกรมประยุกต์บนเดสก์ท็อปสำหรับช่วยนักวิจัยและนักเรียนนักศึกษาในการคำนวณสถิติพื้นฐานจากแบบสอบถามหรือแบบประเมินความพึงพอใจการใช้งาน โดยผู้ใช้สามารถกำหนดจำนวนผู้ตอบและข้อคำถามได้อย่างอิสระ ระบบจะสร้างช่องสำหรับกรอกคะแนนแบบไดนามิก และประมวลผลคะแนนรวม ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน (S.D.) และค่าสัมประสิทธิ์การแปรผัน (C.V. %) ให้อัตโนมัติในทันที พร้อมทั้งป้องกันข้อผิดพลาดกรณีค่าเฉลี่ยเป็นศูนย์หรือการป้อนค่าที่ไม่ใช่ตัวเลข
