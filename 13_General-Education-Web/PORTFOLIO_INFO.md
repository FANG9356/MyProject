# Project Portfolio Information

## ชื่อโครงการ
เว็บไซต์แนะนำการศึกษาประเภทวิชาสามัญ (General Education Web Portal - Seniormath)

## ผู้พัฒนา
ภคพล สุขมี (Phakhaphon Sukmee)

## หมวดหมู่
Web Application / Educational Technology / Frontend Development

## เทคโนโลยีที่ใช้
- สถาปัตยกรรม: Multi-Page Web Application
- ภาษา: HTML5, CSS3, JavaScript (ES6)
- การออกแบบส่วนติดต่อผู้ใช้: CSS Flexbox, Grid Layout, Glassmorphism, CSS Transitions & Keyframe Animations
- สื่อประกอบ: Background Video Embedding, Canvas Interactive Graphics, Audio Player Integration

## สรุปภาพรวมและผลการดำเนินงาน
พอร์ทัลแนะนำการศึกษานี้สร้างขึ้นเพื่อเป็นแหล่งเรียนรู้ด้วยตนเองสำหรับนักเรียนและนักศึกษาในกลุ่มสาระการเรียนรู้วิชาสามัญ ได้แก่ คณิตศาสตร์ ฟิสิกส์ ไฟฟ้าอิเล็กทรอนิกส์ และวิทยาการคอมพิวเตอร์ ระบบประกอบด้วยบทเรียนสรุป เครื่องคิดเลขสำหรับช่วยตรวจคำตอบ และเครื่องมือแปลงระบบเลขฐาน ช่วยเพิ่มความเข้าใจในบทเรียนผ่านสื่ออินเทอร์แอคทีฟ
