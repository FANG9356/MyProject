# Step 2: Create new dashboard:
Left menu "Dashboards" -> Add visualization -> Select mysql:

# Set timezone UTC
Right menu "Time options" -> Timezone: "Local browser time" (Default UTC)

# Create temperature chart
Right menu "Time series" (Chart):
  Title: Temperature
  Unit: Temperature -> Celsius (°C)

"Tab Queries"
Select tab "Code":

SELECT
  timestamp AS "time",
  temperature AS "Temperature"
FROM bmp280_data
WHERE $__timeFilter(timestamp)
ORDER BY timestamp ASC

Click "Run query" button
Select: Last 1 hours

Right menu "Time series" (Chart):
  + Add field override
    Fields with name: Temperature
    + Add override property: Standard options -> Color scheme:
      Select Single color: "select  your color want"


Top-right: Click "Save dashboard" button:
  Title: "BMP280IoT Dashboard" 
  Click "Save" button
