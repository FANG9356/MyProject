# การลงทะเบียน Runner (Register)
# ขั้นตอนที่ 1: นำ Token จาก GitLab
  1. เข้าสู่ระบบ GitLab ของคุณ (เช่น http://gitlab.naphat.demo) ด้วยสิทธิ์ Admin -> ไปที่เมนู Admin Area -> CI/CD -> Runners
  2. คลิกปุ่ม "Create instance runner" (มุมขวาบน):
    Tags: docker,build (สำคัญ! ต้องตรงกับที่เรียกใช้ใน Pipeline)
    Runner description: "docker-runner-01"
  3. คลิกปุ่ม "Create runner":
      Operating systems: Linux

# ขั้นตอนที่ 2: รันคำสั่ง Register ที่ได้จากการ คลิกปุ่ม "Create runner"
docker exec -it gitlab-runner bash
gitlab-runner register
  --url : คัดลอกได้จากการ คลิกปุ่ม "Create runner"
  --token : คัดลอกได้จากการ คลิกปุ่ม "Create runner"
  Enter name for the runner: docker-runner-01
  Enter an executor: docker
  Enter the default Docker image: node:latest
