#ใช้ในกรณี รับ IP จาก Ethernet Card และต้องการทำ WiFi Card เป็น Access Point

# 1. Check your WiFi Interface name that starts with "wlan" or "wlp":
ip a

# 2. Install the Required Packages:
apt update && apt install hostapd dnsmasq iptables-persistent -y

# 3. Set a Static IP for the WiFi Interface:
nano /etc/network/interfaces

# Edit file "interfaces" (Change "wlan0" to your wlan name (e.g.: wlp4s0)):
# Static IP
auto wlp4s0 
iface wlp4s0 inet static
    address 10.10.10.1/24

# Network Bridge
auto wlp4s0
iface wlp4s0 inet manual

# Apply the interface
ifdown wlp4s0 && ifup wlp4s0

# 4. Configure DHCP and DNS (dnsmasq):
touch /etc/dnsmasq.conf
mv /etc/dnsmasq.conf /etc/dnsmasq.conf.orig
nano /etc/dnsmasq.conf

# Edit file "dnsmasq.conf":
interface=wlp4s0
dhcp-range=10.10.10.2,10.10.10.254,255.255.255.0,24h
dhcp-option=3,10.10.10.1
dhcp-option=6,Your DNS Server IP,8.8.8.8,8.8.4.4

# Restart the service:
systemctl restart dnsmasq

# If want to use "Network Bridge", Disable DHCP Server:
systemctl stop dnsmasq
systemctl disable dnsmasq

# 5: Configure the Access Point(hostapd):
nano /etc/hostapd/hostapd.conf
# Edit file "hostapd.conf": change the interface, ssid (your WiFi name), and wpa_passphrase (your WiFi password):

interface=wlp4s0
#bridge=vmbr0 (Remove "#" For Network Bridge)
hw_mode=g
#hw_mode=a # For 5Ghz
channel=6
#channel=36, (40, 44, 48) # For 5Ghz
ieee80211n=1
wmm_enabled=1
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpa_passphrase=11111111
wpa_key_mgmt=WPA-PSK
rsn_pairwise=CCMP
ssid=MyProxmox-DevOps-WiFi

nano /etc/default/hostapd
# Edit file "hostapd": remove the # and add the path:
DAEMON_CONF="/etc/hostapd/hostapd.conf"

systemctl unmask hostapd
systemctl enable hostapd
systemctl restart hostapd

# 6. Route Traffic to the Internet (NAT):
nano /etc/sysctl.conf
# Edit file "sysctl.conf":
net.ipv4.ip_forward=1

# Apply the kernel change
sysctl -p

# Add a firewall rule to route the WiFi traffic out through your main Proxmox bridge:
iptables -t nat -A POSTROUTING -o vmbr0 -j MASQUERADE
iptables -A FORWARD -i wlp4s0 -o vmbr0 -j ACCEPT
iptables -A FORWARD -i vmbr0 -o wlp4s0 -m state --state RELATED,ESTABLISHED -j ACCEPT

# Save the firewall rule so it survives a reboot:
netfilter-persistent save

# Delete iptables:
iptables -t nat -F
iptables -F
iptables -t nat -L -n -v

nano /etc/sysctl.conf
# Edit file "sysctl.conf":
net.ipv4.ip_forward=0

cat /proc/sys/net/ipv4/ip_forward
netfilter-persistent save
