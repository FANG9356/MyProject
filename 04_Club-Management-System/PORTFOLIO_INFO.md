# Club Member Registration & Attendance Management System

**หมวดหมู่:** Full-Stack Web Application & Educational Management  
**เทคโนโลยีหลัก (Tech Stack):** Node.js, Express.js, SQLite3, Tailwind CSS, JWT Authentication, HTML5/Vanilla JS  

---

## 📌 ภาพรวมและจุดเด่นของผลงาน (Portfolio Pitch)
ระบบบริหารจัดการสมาชิกและเช็คชื่อเข้าร่วมกิจกรรมชมรมในสถานศึกษา รองรับการลงทะเบียน, เช็คชื่อประจำวัน, หน้า Dashboard ผู้ดูแลระบบ (Admin) และสิทธิ์ Superadmin เพื่อจัดการข้อมูลอย่างเป็นระบบและปลอดภัย

## 🚀 วิธีการรันและทดสอบระบบ (How to Run)
```bash
cd backend && node server.js (เข้าใช้งานผ่าน http://localhost:3000)
```
