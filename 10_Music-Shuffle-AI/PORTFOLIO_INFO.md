# Music Shuffle AI — Desktop Music Player with Whisper Voice Control

**หมวดหมู่:** Desktop Application & AI Audio
**เทคโนโลยีหลัก (Tech Stack):** Python, PyQt6, faster-whisper (OpenAI Whisper), mutagen, yt-dlp

---

## ภาพรวมโครงการ (Project Overview)
โปรแกรมเล่นเพลงบนเดสก์ท็อปที่พัฒนาด้วย PyQt6 รองรับการจัดคิวเพลง การจัดการเพลย์ลิสต์ การดึงปกอัลบั้มอัตโนมัติ และแสดงเนื้อเพลงคาราโอเกะแบบซิงค์เวลาจริง ตัวโปรแกรมเชื่อมต่อโมเดล faster-whisper เพื่อให้สามารถค้นหาเพลงหรือสั่งงานด้วยเสียงภาษาไทยและภาษาอังกฤษได้ในเครื่อง

---

## วิธีการรันและทดสอบระบบ (How to Run)
```bash
pip install -r requirements.txt
python3 main.py
```

โหมดทดสอบด่วน (Quick Test):
```bash
python3 test_simulation.py
```
