# Smart Karaoke Studio — Self-Hosted Streaming & Mobile Remote Control

**หมวดหมู่:** Multimedia Server & Web Application  
**เทคโนโลยีหลัก (Tech Stack):** FastAPI (Python), yt-dlp, HTML5 Audio/Video, WebSocket/REST API, Docker  

---

## 📌 ภาพรวมและจุดเด่นของผลงาน (Portfolio Pitch)
ระบบคาราโอเกะสตรีมมิ่งติดตั้งใช้งานเองในบ้าน ค้นหาและเล่นเพลงจาก YouTube พร้อมระบบบายพาสคุกกี้ และมีหน้า Web Remote สำหรับให้เพื่อน ๆ ใช้สมาร์ทโฟนสแกน QR Code เข้ามาค้นหาและกดแทรกคิวเพลงได้พร้อมกัน

---

## 🚀 วิธีการรันและทดสอบระบบ (How to Run)
```bash
python3 main.py (เข้าหน้าเล่นเพลงที่ http://localhost:8000 และรีโมตที่ http://localhost:8000/remote.html)
```
