# Tip Desk — Real-time PromptPay Donation & Voice Alert System

**หมวดหมู่:** FinTech / Full-Stack Web Application  
**เทคโนโลยีหลัก (Tech Stack):** React 19, TypeScript, Vite, FastAPI, SQLite, EMVCo PromptPay QR Code Generator, Web Speech API (TTS)  

---

## 📌 ภาพรวมและจุดเด่นของผลงาน (Portfolio Pitch)
ระบบรับเงินบริจาค/ทิปส่วนตัวแบบเรียลไทม์ สร้าง PromptPay QR Code ตามมาตรฐาน EMVCo อัตโนมัติ พร้อมระบบแจ้งเตือนแบบสดและเสียงอ่านข้อความผู้สนับสนุนด้วย Text-to-Speech (TTS)

---

## 🚀 วิธีการรันและทดสอบระบบ (How to Run)
```bash
Backend: uvicorn backend.main:app --reload --port 8000
Frontend: npm run dev (เข้า http://localhost:5173)
```
