# ระบบติดตามพิกัดหุ่นยนต์และข้อมูลความชื้นเรียลไทม์ (Project 21)

## ข้อมูลผลงาน
- ผู้พัฒนา: Phakhaphon Sukmee
- ประเภทโครงงาน: Robotics Telemetry, Geospatial Tracking, IoT Dashboard
- เทคโนโลยี: Leaflet.js, OpenStreetMap, Firebase Realtime Database, JavaScript, HTML5/CSS3

## สถาปัตยกรรมและฟังก์ชันการทำงาน
1. **การแสดงตำแหน่งพิกัดภูมิศาสตร์แบบเรียลไทม์**
   - พล็อตตำแหน่งพิกัด GPS ละติจูดและลองจิจูดของหุ่นยนต์สำรวจลงบนแผนที่อินเทอร์แอคทีฟ
   - ปรับปรุงการเคลื่อนที่แบบไดนามิกเมื่อได้รับข้อมูลพิกัดใหม่

2. **การวัดและแสดงผลข้อมูลความชื้นในดิน**
   - แสดงค่าร้อยละของความชื้นในดิน (Soil Moisture Percentage)
   - มีแถบสรุปสถานะการทำงาน (Standby, Moving to Target, Measuring Active)

3. **การส่งคำสั่งกำหนดเป้าหมาย (Waypoint Dispatching)**
   - คลิกบนแผนที่เพื่อสร้างหมุดเป้าหมายใหม่ (Target Pin)
   - ส่งคำสั่งพิกัดเป้าหมายไปยังโหนดคำสั่งของหุ่นยนต์เพื่อสั่งการเคลื่อนที่อัตโนมัติ
