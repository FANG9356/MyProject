# Project Portfolio Information

## ชื่อโครงการ
เว็บไซต์ทำแบบทดสอบพื้นฐานคอมพิวเตอร์ (Computer Fundamentals Online Quiz System)

## ผู้พัฒนา
ภคพล สุขมี (Phakhaphon Sukmee)

## หมวดหมู่
Web Application / EdTech / Assessment System

## เทคโนโลยีที่ใช้
- ภาษาหลัก: HTML5, CSS3, JavaScript (ES6)
- ฐานข้อมูลข้อสอบ: JSON Data Structure (400 ข้อ)
- กลไกการประมวลผล: Asynchronous Fetch API, DOM Manipulation, Regular Expression Validation
- ความปลอดภัยฝั่งไคลเอนต์: Clipboard API Protection (Disable Copy/Cut)

## สรุปภาพรวมและผลการดำเนินงาน
ระบบแบบทดสอบออนไลน์นี้ถูกพัฒนาขึ้นเพื่อสนับสนุนการเรียนการสอนและการวัดผลสัมฤทธิ์ทางการเรียนในวิชาพื้นฐานคอมพิวเตอร์ ผู้เรียนสามารถเข้าสู่ระบบเพื่อทำแบบทดสอบ 400 ข้อ ครอบคลุมทั้งฮาร์ดแวร์ ซอฟต์แวร์ เครือข่าย และความปลอดภัย โดยมีระบบประเมินผลคะแนนแบบเรียลไทม์ พร้อมการคำนวณร้อยละและคะแนนตัดเกรดอย่างถูกต้องแม่นยำ
