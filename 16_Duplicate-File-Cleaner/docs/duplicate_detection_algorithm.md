# ขั้นตอนวิธีตรวจจับและจัดการไฟล์ซ้ำซ้อน (Duplicate File Detection Algorithm)

เอกสารทางเทคนิคอธิบายสถาปัตยกรรมและขั้นตอนวิธีของโปรแกรมค้นหาไฟล์ซ้ำ (Duplicate File Cleaner) พัฒนาด้วย Python และ CustomTkinter

## 1. ปัญหาและความท้าทาย

การสแกนค้นหาไฟล์ซ้ำในระบบจัดเก็บข้อมูลขนาดใหญ่ (ฮาร์ดดิสก์หรือไดรฟ์เครือข่าย) มีความท้าทายหลัก 2 ประการ:
1. การเปรียบเทียบระดับไบต์ (Byte-by-Byte Comparison) มีความซับซ้อนระดับ $O(N^2)$ ซึ่งใช้เวลาและ I/O สูงมาก
2. การคำนวณ Cryptographic Hash (SHA-256) ทุกไฟล์โดยตรงจะสิ้นเปลือง I/O สำหรับไฟล์ที่มีขนาดไม่เท่ากันอย่างสิ้นเชิง

## 2. ขั้นตอนวิธีการจัดกลุ่ม 2 ระดับ (Two-Tier Grouping Architecture)

เพื่อประสิทธิภาพสูงสุด ระบบใช้กลยุทธ์กรอง 2 ชั้น:

### ชั้นที่ 1: การกรองด้วยขนาดไฟล์ (File Size Pre-filtering)
- สแกนไดเรกทอรีแบบวนซ้ำด้วย `os.walk()`
- ตรวจสอบขนาดไฟล์ด้วย `os.path.getsize()`
- จัดกลุ่มไฟล์ลงในพจนานุกรม `files_by_size = defaultdict(list)` โดยใช้ขนาดเป็นคีย์
- ไฟล์ที่มีขนาดไม่ซ้ำกับไฟล์อื่นจะถูกคัดทิ้งทันทีโดยไม่ต้องอ่านข้อมูลลงลึก

### ชั้นที่ 2: การตรวจสอบค่าแฮช SHA-256 แบบแบ่งบล็อก (Chunked SHA-256 Hashing)
- นำเฉพาะกลุ่มไฟล์ที่มีขนาดเท่ากันมาคำนวณแฮช
- อ่านข้อมูลทีละบล็อกขนาด 64 KB (`block_size = 65536`) เพื่อไม่ให้เปลืองหน่วยความจำแรมแม้ไฟล์มีขนาดหลายกิกะไบต์
- จัดกลุ่มไฟล์ที่มีค่าแฮชตรงกันอย่างแท้จริง (`final_duplicates = {k: v for k, v in duplicates.items() if len(v) > 1}`)

## 3. การแสดงผลและการลบไฟล์อย่างปลอดภัย (Safe Deletion Workflow)

- แสดงรายการกลุ่มไฟล์ซ้ำแยกตาม Hash Prefix (8 ตัวแรก)
- ผู้ใช้งานสามารถเลือกไฟล์ที่ต้องการลบผ่านกล่อง Checkbox
- แสดงหน้าต่างยืนยันการลบ (Confirmation Dialog) ก่อนดำเนินการ
- ดำเนินการลบด้วย `os.remove()` พร้อมการดักจับข้อผิดพลาด `OSError` และสรุปผลสำเร็จ
