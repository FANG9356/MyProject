## ภาพรวมของโครงการ

โครงการสร้างเครื่องคัดแยกขวดพลาสติกและกระป๋องเครื่องดื่มอัตโนมัติ เพื่อสนับสนุนกระบวนการรีไซเคิลขยะและส่งเสริมการจัดการสิ่งแวดล้อม ตัวเครื่องทำงานผ่านระบบควบคุมไมโครคอนโทรลเลอร์ Arduino Uno ร่วมกับเซ็นเซอร์ตรวจจับวัสดุและกลไกคัดแยกแบบสองทิศทาง

### หลักการทำงานและเซ็นเซอร์ที่ใช้
1. **Ultrasonic Sensor (HC-SR04):** ตรวจจับระยะของบุคคลที่เดินเข้ามาใกล้ เมื่อระยะน้อยกว่า 70 เซนติเมตร ระบบจะสั่งให้เซอร์โวมอเตอร์ตัวที่หนึ่งหมุนเปิดฝารับขยะโดยอัตโนมัติ และเปิดไฟแบ็กไลต์หน้าจอ LCD
2. **Proximity Sensor & Inductive/Capacitive Sensor:** ตรวจจับคุณสมบัติความเป็นโลหะของขยะที่หย่อนลงมา หากตรวจพบโลหะจะจำแนกเป็นกระป๋อง (Metal Can) หากไม่พบโลหะจะจำแนกเป็นขวดพลาสติก (Plastic Bottle)
3. **HX711 Load Cell Weight Sensor:** ชั่งน้ำหนักของวัสดุเพื่อตรวจสอบความถูกต้องและคำนวณปริมาณมวลรวม
4. **Stepper Motor (28BYJ-48):** ควบคุมรางเลื่อนคัดแยก หมุนไปทางซ้ายเมื่อเป็นขวดพลาสติก และหมุนไปทางขวาเมื่อเป็นกระป๋องโลหะ
5. **Servo Motor (SG90):** ผลักวัตถุลงสู่ช่องกักเก็บแยกประเภท
6. **I2C LCD Display (16x2):** แสดงผลจำนวนนับของขวดพลาสติกและกระป๋องแบบเรียลไทม์ พร้อมแจ้งเตือนสถานะ FULL เมื่อช่องเก็บขยะเต็มความจุ (ตั้งแต่ 10 ชิ้นขึ้นไป)

## โครงสร้างซอร์สโค้ด

* [`arduino/bottle_can_sorter.ino`](./arduino/bottle_can_sorter.ino): ซอร์สโค้ดภาษา C++ สำหรับเฟิร์มแวร์ Arduino Uno ควบคุมเซ็นเซอร์ สเต็ปเปอร์ เซอร์โว และหน้าจอแสดงผล
* [`arduino/HX711_full_example/`](./arduino/HX711_full_example/): โฟลเดอร์ไลบรารีและโค้ดตัวอย่างการสอบเทียบโหลดเซลล์ชั่งน้ำหนัก
* [`sorter_sim.html`](./sorter_sim.html): หน้าแดชบอร์ดจำลองกลไกการทำงานของเครื่องคัดแยกและมาตรวัดเซ็นเซอร์แบบอินเทอร์แอคทีฟ
* [`test_simulation.py`](./test_simulation.py): สคริปต์ทดสอบตรรกะการคัดแยกและการตอบสนองของเซ็นเซอร์แบบอัตโนมัติ

## การทดสอบระบบ

รันสคริปต์ทดสอบจำลองการทำงานของฮาร์ดแวร์:
```bash
python3 test_simulation.py
```

