# Project Portfolio Information

## ชื่อโครงการ
เว็บไซต์คุยแชทออนไลน์ และระบบแชทออฟไลน์ BLE (Neo-Brutalist Web Chat & Offline BLE Mesh)

## ผู้พัฒนา
ภคพล สุขมี (Phakhaphon Sukmee)

## หมวดหมู่
Web Application & Wireless Networking / Real-Time Messaging / IoT Communication

## เทคโนโลยีที่ใช้
- Frontend: HTML5, Tailwind CSS, JavaScript (ES6+), Neo-Brutalist Architecture
- Cloud Backend: Firebase Realtime Database, Firebase Authentication
- Wireless / Offline Stack: Web Bluetooth API, Bluetooth Low Energy (BLE GATT Profiles), Nordic UART Protocol
- Desktop Client: Python 3, Tkinter GUI, Bleak (Asynchronous BLE Library), asyncio

## สรุปภาพรวมและผลการดำเนินงาน
ระบบสื่อสารข้อความสองโหมดที่ผสานระหว่างการสนทนาผ่านเครือข่ายอินเทอร์เน็ตบนคลาวด์ และการสนทนาในภาวะฉุกเฉินหรือนอกพื้นที่สัญญาณผ่านโครงข่ายไร้สายบลูทูธ (Bluetooth Low Energy) ส่วนติดต่อผู้ใช้ได้รับการออกแบบด้วยอัตลักษณ์แบบ Neo-Brutalism ให้ความรู้สึกหนักแน่น คมชัด ตอบสนองต่อการรับส่งข้อความแบบเรียลไทม์ พร้อมด้วยไคลเอนต์ฝั่งเดสก์ท็อปที่สามารถเชื่อมต่อกับฮาร์ดแวร์ ESP32 ได้โดยตรง
