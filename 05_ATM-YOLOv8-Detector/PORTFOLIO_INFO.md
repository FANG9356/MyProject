# ATM Security & Person Detection System (Computer Vision)

**หมวดหมู่:** Computer Vision & Smart Surveillance  
**เทคโนโลยีหลัก (Tech Stack):** Python, OpenCV, Ultralytics YOLOv8 (yolov8n.pt), JSON Logging, Image Processing  

---

## 📌 ภาพรวมโครงการ (Project Overview)
ระบบตรวจจับบุคคลและเฝ้าระวังความปลอดภัยหน้าตู้ ATM ด้วย Computer Vision ใช้โมเดล YOLOv8 ตรวจจับบุคคลแบบเรียลไทม์ พร้อมบันทึกภาพถ่าย Snapshot และเก็บสถิติประวัติการเข้าใช้งานลง JSON Log
