# ระบบตรวจจับสีวัตถุแบบเรียลไทม์และกรองสัญญาณด้วย Kalman Filter (Project 20)

## ข้อมูลผลงาน
- ผู้พัฒนา: Phakhaphon Sukmee
- ประเภทโครงงาน: Computer Vision, Real-Time Signal Processing, Deep Learning
- เทคโนโลยี: Python, OpenCV, NumPy, YOLOv8, Kalman Filter, K-Means Clustering

## สถาปัตยกรรมและหลักการทำงาน
1. **การสกัดสีเด่นด้วย K-Means Clustering**
   - ตัดส่วนของภาพวัตถุจากกรอบ Bounding Box ที่ตรวจจับได้
   - ใช้อัลกอริทึม K-Means แบ่งกลุ่มพิกเซลเพื่อค้นหาค่าสี BGR ที่เป็นตัวแทนของวัตถุที่มีความถี่สูงสุด

2. **การแปลงสีและจับคู่ชื่อสีภาษาไทยผ่าน HSV Space**
   - แปลงรหัสสี BGR เป็น HSV เพื่อลดผลกระทบจากความเข้มแสงเงา
   - จำแนกช่วงสีพื้นฐาน ได้แก่ แดง ส้ม เหลือง เขียว ฟ้า น้ำเงิน ม่วง ดำ ขาว และเทา

3. **การประมาณค่าระยะทางและกรองสัญญาณรบกวนด้วย Kalman Filter**
   - ออกแบบตัวกรอง 1D Kalman Filter สำหรับทำนายและลดความผันผวนของการวัดขนาดวัตถุและระยะห่างในวิดีโอสตรีมแบบเรียลไทม์
