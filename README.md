## 🌟 รายละเอียดจุดเด่นของแต่ละผลงาน (Portfolio Highlights)

### 01. AI Wi-Fi Sensing & Activity Recognition (Wall Penetration)
* **จุดเด่น:** ระบบตรวจจับการเคลื่อนไหวของมนุษย์ทะลุกำแพงโดยไม่ต้องใช้กล้อง โดยดักจับและวิเคราะห์คลื่นวิทยุ WiFi CSI ผ่าน ESP32 นำมาสกัดคุณลักษณะ (Feature Extraction) และจำแนกท่าทาง (เดิน, หกล้ม, ห้องว่าง) ด้วยโมเดล Machine Learning แบบเรียลไทม์
* **เหมาะสำหรับนำเสนอ:** ด้านฮาร์ดแวร์ IoT, ปัญญาประดิษฐ์ (AI), และงานวิจัยเชิงนวัตกรรม

### 02. Smart Doc AI — Automated Academic Research & Document Generator
* **จุดเด่น:** ระบบ AI Agent ช่วยค้นคว้าวิจัยและร่างเอกสารวิชาการอัตโนมัติ เพียงกรอกหัวข้อ ระบบจะค้นคว้าข้อมูลจาก Wikipedia, งานวิจัย ArXiv และสารสนเทศบนเว็บ สรุปเนื้อหา และสร้างออกมาเป็นไฟล์ Word (`.docx`) ตาม Template มาตรฐานพร้อมจัดหน้า
* **เหมาะสำหรับนำเสนอ:** ด้าน Full-Stack Web Development, LLM & AI Agents, การดึงข้อมูลอัตโนมัติ

### 03. Tip Desk — Real-time PromptPay Donation & Voice Alert System
* **จุดเด่น:** ระบบรับบริจาคเงินแบบเรียลไทม์ พร้อมสร้าง PromptPay QR Code มาตรฐาน EMVCo อัตโนมัติ รองรับระบบเสียงอ่านชื่อผู้สนับสนุนด้วย Web Speech API (Text-to-Speech)
* **เหมาะสำหรับนำเสนอ:** ด้าน FinTech, Modern Frontend (React 19), และ Real-time Architecture

### 04. Club Member Registration & Attendance Management System
* **จุดเด่น:** ระบบบริหารจัดการสมาชิกและเช็คชื่อเข้าร่วมกิจกรรมในสถานศึกษา มีระบบยืนยันตัวตน JWT, สิทธิ์ Superadmin, หน้าบันทึกสถิติและข้อมูลสมาชิก
* **เหมาะสำหรับนำเสนอ:** ด้าน Database Management, User Authorization, ผลงานที่ประยุกต์ใช้จริงในโรงเรียน/วิทยาลัย

### 05. ATM Security & Person Detection System
* **จุดเด่น:** ระบบเฝ้าระวังความปลอดภัยหน้าตู้ ATM ด้วย Computer Vision ใช้โมเดล YOLOv8 ตรวจจับบุคคลแบบเรียลไทม์ พร้อมบันทึกภาพถ่าย Snapshot และเก็บสถิติลง JSON Log
* **เหมาะสำหรับนำเสนอ:** ด้าน Computer Vision, Image Processing, Smart Surveillance

### 06. Fang Karaoke — Self-Hosted Streaming & Mobile Remote Control
* **จุดเด่น:** ระบบคาราโอเกะสตรีมมิ่งสำหรับใช้งานภายในบ้าน ค้นหาและเล่นเพลงจาก YouTube พร้อมระบบบายพาสคุกกี้ และมีหน้า Web Remote ให้เพื่อน ๆ ใช้มือถือสแกนเข้ามาเลือกและแทรกคิวเพลงได้พร้อมกัน
* **เหมาะสำหรับนำเสนอ:** ด้าน Multimedia Streaming, WebSocket, API Integration

### 07. AdGuard Time Portal — Internet Access & Quota Control
* **จุดเด่น:** ระบบบริหารจัดการเวลาและจำกัดการเข้าถึงอินเทอร์เน็ตของอุปกรณ์ในวงแลน เชื่อมโยงผ่าน AdGuard Home API เพื่อสั่งบล็อก/ปลดบล็อกตามเวลาหรือโควต้า
* **เหมาะสำหรับนำเสนอ:** ด้าน Network Administration, Network Automation

### 08. Fang Monitor App — Windows Standalone System Monitor
* **จุดเด่น:** โปรแกรมตรวจสอบสถานะฮาร์ดแวร์และระบบแบบ Lightweight แพ็กเกจเป็นไฟล์ `.exe` แบบ Standalone บน Windows ไม่ต้องพึ่งพาสภาพแวดล้อมอื่น
* **เหมาะสำหรับนำเสนอ:** ด้าน System Utilities, Cross-Platform Desktop App

### 09. Fang Home Server & DevOps Infrastructure
* **จุดเด่น:** สถาปัตยกรรม Home Server & Private Cloud รวม Dashboard มอนิเตอร์เครื่องเซิร์ฟเวอร์, Docker Containers, Proxmox Node และบริการภายในบ้านทั้งหมด ปลอดภัยด้วย Cloudflare Tunnels
* **เหมาะสำหรับนำเสนอ:** ด้าน Cloud Infrastructure, Docker, Linux Server Administration, DevOps
