# AdGuard Time Portal — Internet Access & Quota Control

**หมวดหมู่:** Network & System Administration  
**เทคโนโลยีหลัก (Tech Stack):** Node.js, Express.js, AdGuard Home API, SQLite, Node-Schedule  

---

## 📌 ภาพรวมและจุดเด่นของผลงาน (Portfolio Pitch)
ระบบควบคุมและจำกัดเวลาการเข้าถึงอินเทอร์เน็ตผ่านเครือข่าย โดยเชื่อมต่อ AdGuard Home API เพื่อสั่งบล็อก/ปลดบล็อกอุปกรณ์ในวงแลนตามตารางเวลาหรือเงื่อนไขที่กำหนด

---

## 🚀 วิธีการรันและทดสอบระบบ (How to Run)
```bash
node server.js (เข้าหน้าแอดมินที่ http://localhost:8080/admin.html)
```
