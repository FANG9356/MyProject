# คู่มือเกณฑ์มาตรฐานการคำนวณเกรด (Academic Grading System Manual)

เอกสารอ้างอิงเกณฑ์มาตรฐานการตัดเกรด การคำนวณแต้มระดับคะแนน (Grade Point) ระดับผลการเรียนเฉลี่ยรายภาค (GPA) และระดับผลการเรียนเฉลี่ยสะสม (GPAX) ตามระบบอุดมศึกษาและอาชีวศึกษาไทย

## 1. ตารางเกณฑ์การตัดเกรด 8 ระดับ (8-Tier Standard Grading Scale)

| ช่วงคะแนนดิบ (0-100) | สัญลักษณ์เกรด (Grade) | แต้มระดับคะแนน (Grade Point) | ความหมาย |
| :---: | :---: | :---: | :---: |
| 80 – 100 | A | 4.0 | ดีเยี่ยม (Excellent) |
| 75 – 79 | B+ | 3.5 | ดีมาก (Very Good) |
| 70 – 74 | B | 3.0 | ดี (Good) |
| 65 – 69 | C+ | 2.5 | ดีพอใช้ (Fairly Good) |
| 60 – 64 | C | 2.0 | พอใช้ (Fair) |
| 55 – 59 | D+ | 1.5 | อ่อน (Poor) |
| 50 – 54 | D | 1.0 | อ่อนมาก (Very Poor) |
| ต่ำกว่า 50 | F | 0.0 | ตก (Fail) |

## 2. สูตรการคำนวณแต้มคะแนนเฉลี่ยรายภาค (GPA)

$$ \text{GPA} = \frac{\sum_{i=1}^{n} (W_i \times G_i)}{\sum_{i=1}^{n} W_i} $$

โดยที่:
- $W_i$ คือ จำนวนหน่วยกิตของวิชาที่ $i$ (Credit Hours)
- $G_i$ คือ แต้มระดับคะแนนของวิชาที่ $i$ (Grade Point: 0.0 - 4.0)
- $n$ คือ จำนวนวิชาทั้งหมดที่ลงทะเบียนในภาคนั้น

## 3. สูตรการคำนวณแต้มคะแนนเฉลี่ยสะสม (GPAX)

$$ \text{GPAX} = \frac{(\text{GPA}_{\text{เดิม}} \times W_{\text{เดิม}}) + \sum (W_{\text{ใหม่}} \times G_{\text{ใหม่}})}{W_{\text{เดิม}} + W_{\text{ใหม่}}} $$

โดยที่:
- $\text{GPA}_{\text{เดิม}}$ คือ เกรดเฉลี่ยสะสมจากภาคการศึกษาก่อนหน้า
- $W_{\text{เดิม}}$ คือ จำนวนหน่วยกิตสะสมที่ผ่านมา
- $W_{\text{ใหม่}}$ คือ หน่วยกิตที่ลงทะเบียนในภาคเรียนปัจจุบัน
- $G_{\text{ใหม่}}$ คือ แต้มเกรดของวิชาในภาคเรียนปัจจุบัน
