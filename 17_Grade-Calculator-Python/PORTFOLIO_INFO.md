# Project Portfolio Information

## ชื่อโครงการ
โปรแกรมคำนวณเกรด ด้วย Python (GPA & GPAX Academic Grade Calculator)

## ผู้พัฒนา
ภคพล สุขมี (Phakhaphon Sukmee)

## หมวดหมู่
Desktop Application / Educational Software / Python Tools

## เทคโนโลยีที่ใช้
- ภาษาหลัก: Python 3
- ส่วนติดต่อผู้ใช้ (GUI): CustomTkinter (CTkScrollableFrame, CTkEntry, CTkLabel, CTkButton)
- การประมวลผลและการคำนวณ: ระบบการถ่วงน้ำหนักตามหน่วยกิต (Weighted Average Algorithm)
- ระบบตรวจสอบข้อมูล: Input Validation & Exception Handling

## สรุปภาพรวมและผลการดำเนินงาน
โปรแกรมประยุกต์บนเดสก์ท็อปเพื่ออำนวยความสะดวกแก่นักเรียน นักศึกษา และคณาจารย์ในการวางแผนและคำนวณผลการเรียน โดยสามารถคำนวณได้ทั้งเกรดเฉลี่ยประจำภาคการศึกษา (GPA) และเกรดเฉลี่ยสะสมทุกภาคการศึกษา (GPAX) ระบบแปลงคะแนนดิบเป็นเกรดและแต้มคะแนนตามเกณฑ์มาตรฐาน 8 ระดับ พร้อมส่วนติดต่อผู้ใช้ที่ทันสมัย เรียบง่าย และตอบสนองต่อการใช้งานได้เป็นอย่างดี
